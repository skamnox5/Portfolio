# Details

- **Genre:** Survival Horror
- **Type:** Game Jam Game
- **Software:** Unity 6.3
- **Duration:** 48hr
- **Theme:** Mask
- **Role:** 3D Artist

# 3D Artist

I created various PBR textures for the environments of the game including wood, carpet and wall textures with roughness, bump, AO, diffuse and normal maps. All textures were created using Blender's Ucupaint plugin.

# Programmer

I created a script in C# for triggering sound cues on a timer that gets started upon a player collision overlap event.
